# For You Systeemopschoning

Dit dossier gebruikt nog maar een bron van waarheid:

- [nieuw/architecture](nieuw/architecture): de actuele doelarchitectuur en de Mermaid-diagrammen waar nieuwe implementatiebeslissingen tegen worden gehouden.

De oude architectuurmirror is bewust verwijderd. Die beschreef oude routes en oude modulekaarten die niet meer als waarheid gebruikt mogen worden.

## Werkregel

Pas alleen de documentatie onder `nieuw/architecture` aan wanneer het doelbeeld verandert.

Generated route-, database- en dependency-kaarten zijn verwijderd totdat er een nieuwe generator bestaat. Handmatig bijgewerkte Mermaid-diagrammen zijn voorlopig leidend.
